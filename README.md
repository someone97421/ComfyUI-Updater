# ComfyUI-Updater

用于 Windows 的 ComfyUI 桌面版本管理工具。管理 `custom_nodes` 中的插件，以及 ComfyUI 本体的更新、历史版本和依赖。

## 启动与配置

需要 Python（包含 Tkinter）及 Git，工具本身只使用 Python 标准库。

双击 `Run.bat`。已有 `config.ini` 时使用其中的 Python 路径；首次使用会尝试系统 Python。也可以用带有 Tkinter 的 Python 直接运行 `main.py`。

点击主窗口右上角“环境设置”，在独立设置窗口填写以下内容，然后点击“应用配置”：

- **ComfyUI 根目录**：包含 `custom_nodes` 的目录。
- **Python 路径**：安装 ComfyUI 依赖时使用的解释器，例如便携版的 `python_embeded/python.exe`。如果此解释器没有 Tkinter，请使用另一个带 Tkinter 的 Python 启动界面。
- **Git 路径**：可以填写 `git`，也可以填写 `git.exe` 的完整路径。
- **HTTP 代理**：可选，应用于 Git 和 pip。

配置保存在工具目录下的 `config.ini`，相对路径以工具目录为基准。输入框修改后需要点击“应用配置”。

## 插件管理

- 启动后先列出插件目录，自动联网检查 ComfyUI 本体；本体检查结束后自动并发检查所有插件，结果逐项显示。本体检查失败也会继续检查插件，整个扫描过程不锁定界面。
- 支持按插件名称搜索，以及按有更新、检查失败、非 Git 仓库筛选。
- “刷新”重新读取本地目录；“检查更新”重新获取远端状态。
- 扫描期间可以搜索、选择、更新、安装依赖、打开目录、删除或修改配置，无需等全部检查结束。版本下拉列表和提交历史按选中项加载。双击列表项也可打开目录。
- “批量更新”并发处理所有检测到更新的插件，不受搜索或筛选影响。操作日志逐项记录结果，结束后汇总成功和失败数量。
- 本体选项卡提供 ComfyUI 的版本管理，提交历史直接显示在页内；下方操作栏可切换版本和安装依赖。
- 主窗口默认尺寸为 760×560，支持缩放；插件列表默认选中第一项，完整路径和状态原因显示在版本记录中。

扫描不锁定界面，可以直接关闭窗口。重复刷新会取消上一轮扫描；操作某个仓库时，会取消该仓库剩余的检查，已经运行的 Git 拉取命令先收尾，其他仓库继续扫描。更新、删除和安装任务期间暂停其他修改操作，批量任务内部并发执行；任务完成后可关闭窗口。

## 删除插件

删除会永久移除选中的插件目录，执行前显示完整路径并确认。工具会自动处理 Git 对象文件的只读属性，目录链接只删除链接本身。

如果文件仍被 ComfyUI、终端或其他程序占用，界面会显示失败原因和相关路径。关闭占用程序后可重试；失败时可能已有部分文件被删除。

## 版本与依赖

版本状态区分远端检查失败、存在更新、历史提交和分支状态。本地刷新只反映已有的远端记录；获取最新远端状态请使用“检查更新”。

更新使用 Git 快进更新，本地修改冲突或分支分叉会显示原因。切换历史版本后可选“最新版本 (Latest)”返回远端默认分支。

安装依赖会弹出独立终端，显示 pip 输出；完成后按终端提示关闭窗口，管理器根据 pip 的实际退出码显示结果。

修改插件或本体版本后，请重启 ComfyUI 使变更生效。

## 文件

- `main.py`：Tkinter 界面、配置和任务调度。
- `operations.py`：Git、依赖安装和插件删除。
- `Run.bat`：Windows 启动脚本。
- `config.ini`：本机配置。
